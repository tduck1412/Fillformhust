# Hướng dẫn cài đặt 🐧

Các bước thực hiện:
* **Bước 1:** Tải file `.zip` về máy và giải nén.
* **Bước 2:** Mở trình duyệt **Chrome**, truy cập đường dẫn `chrome://extensions/` hoặc vào **Menu** > **Công cụ khác** > **Tiện ích mở rộng**. Sau đó, bật **Chế độ dành cho nhà phát triển (Developer mode)** ở góc trên bên phải.
* <img width="1919" height="191" alt="image" src="https://github.com/user-attachments/assets/731f81b4-c219-425c-9d68-c8975bdc6506" />

* **Bước 3:** Nhấn vào nút **Tải tiện ích đã giải nén (Load unpacked)**.
* **Bước 4:** Chọn thư mục vừa giải nén ở **Bước 1** là xong!
